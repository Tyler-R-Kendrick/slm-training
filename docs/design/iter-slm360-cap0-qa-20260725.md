# DSH1-08 CAP0 QA views: identity, canonicalization, accepted-set suffix completion (SLM-360)

**Decision:** supported at the deterministic contract-fixture level. CAP0 QA
rows are generated from verified answer artifacts through the closed Harness
DSL (DSH1-03) in three kinds — `IDENTITY` (capped, diagnostic),
`CANONICALIZE` (DSH1-05 proven pairs), and `COMPLETE_SUFFIX` (accepted-set,
never arbitrary single-gold) — with both anti-identity hard-negative kinds,
atomic-production nonidentity coverage, verified-terminal replay, and an
identity-baseline stop rule.

Machine-readable evidence:
[`iter-slm360-cap0-qa-20260725.json`](iter-slm360-cap0-qa-20260725.json).

## Views

`cap0_qa/v1` (`src/slm_training/harnesses/train_data/cap0_qa.py`):

- **IDENTITY** — copy the payload verbatim. Capped at the declared
  `identity_cap` fraction of total rows (`floor(cap / (1 - cap) *
  n_nonidentity)` kept, seeded deterministic selection) and marked
  `diagnostic=True`: identity rows measure the copy shortcut, they never
  dominate training. Guard `identity_rows_within_cap` fails any dataset whose
  identity share exceeds the cap or whose identity rows are not diagnostic
  (tested, including an inflated-identity mix).
- **CANONICALIZE** — expanded surface form → canonical form pairs from the
  DSH1-05 proven equivalence transforms; each row records the
  `CANONICALLY_PREFERRED_TO` relation, transform id/version, margin, and
  equivalence-class fingerprint.
- **COMPLETE_SUFFIX** — statement-boundary prefixes (never a mid-token cut)
  whose payload round-trips through `serialize_harness_task` /
  `parse_harness_task`. For ambiguous prefixes **all** verified accepted
  completions are persisted — each replayed to a verified terminal through
  the DSH1-07 classifier (`classify_partial_state` = `COMPLETE`) — plus a
  **separate** canonical preference (min canonical cost, lexicographic
  tie-break). Rows with multiple accepted completions carry
  `completion=None`; `audit_no_single_gold_where_multi` rejects any dataset
  that attaches a single-gold label there (tested both ways).

## Anti-identity hard negatives

- `same_symbols_different_structure` — two container children swapped:
  identical symbol multiset, parser-verified, different canonical
  fingerprint.
- `matched_structure_permuted_markers` — marker surfaces deranged under the
  marker-table authority discipline (seeded derangement, no marker dropped or
  invented): identical production multiset, parser-verified, different
  canonical fingerprint.

Unverifiable negatives are dropped, never admitted.

## Guards and stop rule

- **Atomic coverage** — every atomic production (DSH1-01 `production_trace`
  ids) used by a staged answer must also appear in at least one nonidentity
  context source; `require_atomic_coverage` fails closed on gaps. Fixture:
  0 uncovered productions.
- **Verified terminals** — `require_verified_terminals` fails closed when any
  accepted completion does not replay to a `COMPLETE` verified terminal.
- **Stop rule** — `identity_baseline_matches` scores the copy shortcut over
  all non-diagnostic rows; when an identity-only baseline matches the whole
  staged suite the views carry no signal and CAP0 must not train
  (`do_not_train=True`). Fixture: baseline score 0.0 on 23 non-diagnostic
  rows → no stop; a synthetic copy-solvable suite trips the rule (tested).
- Non-verified answer artifacts are rejected before any row is emitted.

Every row carries `scoring = accepted_set_membership`: membership/mass over
the accepted set, never a penalty against a valid alternative derivation.
